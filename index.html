Projects

Sentinel Trace

A learning project on AI agent guardrails and continuous evaluation, built for the YC Fall 2026 × Moss Zero Latency Builder Sprint.

What it explores

Explores prompt-injection detection and groundedness evaluation for AI agents.

What I built

  • Prompt check that compares incoming prompts against known injection and jailbreak patterns using Moss vector search, and returns allow or block
  • Groundedness check that scores whether a model's answer is supported by the context it was given
  • SQLite audit log that records each check with its verdict, score and latency
  • FastAPI backend with endpoints for checking, evaluating, viewing the log and stats
  • Next.js dashboard for testing prompts and watching the live trace feed

Tools

  • Python
  • FastAPI
  • SQLite
  • Moss
  • Next.js

What I'd improve next

Measure the guardrail on a labelled set of safe and attack prompts to find false blocks and misses, and add automated backend tests.

Afford-Sense

A Python agent that evaluates whether a purchase is affordable, forecasts cash flow and suggests a payment plan. Built for the HackerRank Orchestrate 24-hour hackathon (September 2026) with AI coding assistance. Learning project — not financial advice.

What it explores

Explores how an AI agent can help with everyday money decisions — evaluating purchase affordability, forecasting cash flow, and suggesting payment strategies based on inputs like income, expenses, and item price.

What I built

  • Reads purchase requests, financial profiles, transactions, exchange rates and payment options from CSV files using pandas
  • Forecasts future balances while protecting the user's minimum balance and essential expenses
  • Classifies each purchase as affordable now, affordable with a plan, affordable later, or not affordable
  • Recommends a payment method (full, partial, installments, wait or not recommended) with a payment schedule
  • Writes the decisions, payment plans and short explanations to a structured output.csv

Tools

  • Python
  • pandas

What I'd improve next

Replace the hand-entered amounts taken from receipt images with automatic extraction, and add a requirements file and tests for the safety rules, such as the balance never dropping below the minimum.
